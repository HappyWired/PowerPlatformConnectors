# Build a Doc Connector
The Build a Doc connector provides a comprehensive set of tools for generating, manipulating, and converting documents within the Microsoft Power Platform. It enables users to automate document workflows, apply templates, and perform advanced operations on Word, PDF, Excel, PowerPoint, OneNote, and Visio files. This connector is designed for business users seeking a scalable, user-friendly solution for document processing.

## Publisher: HappyWired

## Prerequisites
A BuildaDoc subscription is required. Users can sign up for a free plan [here](https://marketplace.microsoft.com/en-us/) via the Azure Marketplace.

## Supported Operations
The Build a Doc connector enables users to convert, merge, compare, update, and extract data across multiple document formats. It also supports chart rendering and data computation in Excel and PowerPoint files.

## Convert HTML
Converts HTML content into a document format of your choice, with optional template support for dynamic content.

## Convert Word Document
Transforms Word documents into other formats or generates custom documents using templates.

## Compare Word Documents
Compares two Word documents and highlights differences for review or auditing purposes.

## Merge Word Documents
Combines multiple Word documents into a single file while preserving formatting and structure.

## Convert OneNote Document
Exports OneNote content into other document formats for broader sharing or integration.

## Convert PDF Document
Converts PDF files into supported formats while maintaining layout and formatting.

## Extract PDF Data
Extracts structured data from PDFs for workflows, reporting, or analysis.

## Update PDF Data
Allows updating of PDF content with new data dynamically.

## Convert Visio Document
Converts Visio files into other supported formats for use in different workflows.

## Convert PowerPoint Document
Transforms PowerPoint presentations into other formats or applies templates for standardised presentations.

## Convert Excel Document
Converts Excel files while supporting templates for dynamic data insertion and formatting.

## Render Excel Chart
Generates charts from Excel data for use in reports and presentations.

## Merge PowerPoint Chart
Combines multiple PowerPoint charts into a single presentation while maintaining design consistency.

## Format PowerPoint Chart
Applies formatting and styling to PowerPoint charts to standardise visuals.

## Compute Data
Performs calculations and data manipulations within Excel or other supported document formats.

## Obtaining Credentials
Users are required authenticate via an API key which is found in the Build a Doc portal. 
To obtain this API key users must first have access to a BuildaDoc subscription, this can be purchased from the Microsoft Marketplace [here](https://marketplace.microsoft.com/en-us/) and then users can be given access to the subscription.
Once a user has purchased a plan they must navigate to the BuildaDoc portal where they can create a new API key and view existing keys. 

## Known Issues and Limitations
None

## Deployment Instructions

This connector is available publicly in **Microsoft Power Automate**.  
Search for **Build A Doc** in the premium connectors list to start using it.
Input the API key generated from the Build a Doc portal.
